# Web feature areas

Add feature-specific React code here as each screen is implemented: `auth`, `onboarding`, `catalog`, `chat`, `offers`, `orders`, `vms`, `usage`, `billing`, `notifications`, `support`, and `provider`.

Keep components, hooks, API calls, types, and feature styles with their feature when they are used only there. Put reused product components in `src/components/`, token-based visual foundations in `src/design-system/`, and HTTP client behavior in `src/lib/api/`.
